## 構成図

`azure-architecture.svg` は、この教材のために作成した構成図です。
編集用の [azure-architecture.drawio](../diagrams/azure-architecture.drawio) を保持しています。
次の Microsoft 公式アイコン集を使っています。

| アイコン集 | バージョン | 使用したアイコン |
|---|---|---|
| [Azure architecture icons](https://learn.microsoft.com/azure/architecture/icons/) | Azure Public Service Icons V24、2026 年 7 月 | Microsoft Foundry、Foundry Models、Azure AI Search、Container Apps、Application Insights、Log Analytics、リソースグループ、テンプレート、ブラウザー、ユーザー |
| [Microsoft Entra architecture icons](https://learn.microsoft.com/entra/architecture/architecture-icons) | 2023 年 10 月 | Microsoft Entra ID |

Microsoft は、リンク先の条件に基づき、構成図・研修資料・文書でのアイコンの使用を許可しています。
元の SVG アイコンの内容は変更せずに埋め込み、縦横比を保って表示しています。
図の構成は Microsoft の参照アーキテクチャ、製品画面の撮影、推奨、デプロイ証跡を表すものではありません。

`workshop-architecture.svg` と `workshop-learning-flow.svg` も教材独自の説明図です。
編集用の `.excalidraw` を保持しており、製品画面や実行証跡とは区別します。
