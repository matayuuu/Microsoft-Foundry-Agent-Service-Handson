# (create_version_from_code/HostedAgentDefinition/CodeConfiguration). Do not
# try to satisfy both from one virtual environment -- install this file's
# pins into their own isolated venv (see README.md's "Two Python
# environments" and labs/08-hosted-multi-agent.md) rather than the repo
# root's .venv, which intentionally keeps the newer azure-ai-projects for
# the deploy/delete scripts instead.
